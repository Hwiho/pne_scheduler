1. **실제 Windows 인수 검사**: 토스트 표시, 알림 비활성 상태, 앱 재시작·로그인·재부팅 후 DB 재개. Mac의 콜백 테스트와 분리한다.

4. **라이브러리 버전 선택**: 현재 UI는 최신 버전만 선택한다. 과거 버전 diff·불러오기·적용 1회 undo를 추가한다. 기존 append-only 파일은 유지한다.
5. **실험 결과 입력**: 실제 SOC setting / 활성화 / derating CSV·XLS·MDB 대표 샘플을 확보한 뒤 열 매핑과 셀 ID 대조를 검증한다. 현재 합성 CSV 성공을 실제 파일 호환으로 간주하지 않는다. 기준용량 직접 입력 기본은 유지한다.
6. **보조 설명의 한국어화·재실행 안내**: 기존 SCH의 상세 추론 설명과 일부 내부 스텝 명칭을 한국어로 제공하고, 재시작/파일 위치 이동 때 경로 진단을 강화한다. 검토 근거·원문은 함께 유지한다.
